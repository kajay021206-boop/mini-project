# 🚀 SkillMatchAI – Smart Job Finder

SkillMatchAI is a frontend-based college mini project designed to help students and job seekers find suitable career opportunities based on their skills, qualifications, experience, and interests.

The project provides a modern and user-friendly interface for job searching, resume management, skill analysis, and application tracking.

## 🎯 Project Objective

The main objective of SkillMatchAI is to create a simple career assistance platform interface where users can:

- Find suitable jobs
- View recommended jobs
- Build and analyze resumes
- Identify skill gaps
- Save jobs
- Track job applications
- Manage their career profile

## ✨ Pages Designed

The frontend currently contains the following pages:

- 🏠 Home / Landing Page
- 🔐 Login Page
- 📝 Create Account Page
- 📊 User Dashboard
- 📄 Resume Builder
- 🤖 Resume Analysis
- 🔎 Find Jobs
- ⭐ Recommended Jobs
- 📈 Skill Gap Analysis
- 🔖 Saved Jobs
- 📋 Applications
